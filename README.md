Kradam Dev — Portfolio
My personal portfolio website. Built from scratch with HTML, CSS, and JavaScript — no frameworks, no build tools, just the fundamentals.

Live Site: https://kradam-portfolio.netlify.app

What's in here
Single-file portfolio (index.html) — everything inline, no external dependencies except Google Fonts
Warm Minimal aesthetic — off-white backgrounds, terracotta accent, serif headings (Fraunces) + sans-serif body (Inter)
Dark/light theme toggle — persisted in localStorage, light is the default
Responsive — mobile-first, works on all screen sizes
Accessible — keyboard navigable, screen reader friendly, respects reduced motion
Contact — direct mailto link, no third-party form services
Sections
Hero — name, tagline, and call-to-action buttons
About — bio, quick-facts sidebar, and a "currently learning" status strip
Projects — placeholder for real-world projects (coming soon)
Skills — categorized by Languages, Tools, and Currently Learning
Contact — email link and GitHub
Tech
HTML5 (semantic)
CSS3 (custom properties, grid, flexbox)
Vanilla JavaScript (IntersectionObserver, localStorage, theme toggle)
Google Fonts (Fraunces, Inter)
How to run locally
Just open index.html in your browser. That's it — no server, no build step, no dependencies to install.
